## Как запустить игру (один файл)

В папке каждой игры лежит один zip-архив с готовой сборкой для Windows.

1. Откройте папку игры, например `Opus 5.5/3. Wave Survival/`.
2. Нажмите на `.zip` файл и скачайте его (кнопка **Download raw file**).
3. Распакуйте архив в любое место.
4. Дважды щёлкните по единственному `.exe` внутри. Игра запустится.

Больше ничего не нужно: ни установки, ни игрового движка.

> Скачивать весь репозиторий (около 400 МБ) необязательно. Можно скачать только нужные игры, по одному архиву. Клонирование репозитория или `Code → Download ZIP` тоже работает, если хотите всё сразу.

### Какой файл запускать

| № | Игра | Движок | Opus 5.5: архив → exe | GPT 6.2 Sol: архив → exe |
|---|------|--------|-----------------------|--------------------------|
| 1 | Destruction Sandbox (разрушения) | Unity | `DestructionSandbox.zip` → `DestructionSandbox.exe` | `DestructionRange.zip` → `DestructionRange.exe` |
| 2 | Drift Racer (дрифт-гонки) | Godot | `DriftRacer.zip` → `DriftRacer.exe` | `DriftRacer.zip` → `DriftRacer.exe` |
| 3 | Wave Survival (шутер на выживание) | Unity | `WaveSurvival.zip` → `WaveSurvival.exe` | `Bastion.zip` → `Bastion.exe` |
| 4 | Living Island (живой остров) | Unity + Blender | `LivingIsland.zip` → `LivingIsland.exe` | `IslandValidation.zip` → `IslandValidation.exe` |
| 5 | Physics Playground (физические головоломки) | Godot | `ContraptionLab.zip` → `ContraptionLab.exe` | `ContraptionLab.zip` → `ContraptionLab.exe` |

Две игры на Godot это один `.exe`. Игры на Unity состоят из `.exe` и папок с `.dll` рядом, поэтому **распаковывайте архив целиком** и запускайте игру прямо оттуда (не вытаскивайте `.exe` отдельно).

### Требования

- Windows 10 или 11, 64-бит
- Современная видеокарта (желательно с поддержкой DirectX 12)

Все игры собирались и проверялись на одном компьютере (RTX 5070 12 ГБ, Ryzen 7 5700X3D, 64 ГБ ОЗУ). На другом железе я их не проверял, поэтому на слабых ПК тяжёлые игры могут работать медленно.

### Предупреждения Windows

Игры не подписаны сертификатом, поэтому Windows может показать **«Windows защитила ваш компьютер»** (SmartScreen), а антивирус может ругнуться. Для неподписанных программ это нормально. Нажмите **Подробнее → Выполнить в любом случае**. Чтобы убедиться, что файлы такие же, как я выложил, сравните их хэши SHA-256 с файлом [`CHECKSUMS.txt`](CHECKSUMS.txt):

```powershell
Get-FileHash .\DriftRacer.zip -Algorithm SHA256
```

## Управление

Клавиши, которые работают во всех играх:

| Клавиша | Действие |
|---------|----------|
| `Esc` | Меню паузы |
| `F1` | Оверлей производительности (FPS, draw calls, физические тела) |
| `F8` | Скрыть или показать **весь** интерфейс игры (удобно для чистых кадров) |
| `F12` | Сохранить скриншот в PNG |

### 1. Destruction Sandbox (обе модели)

| Ввод | Действие |
|------|----------|
| `W` `A` `S` `D`, мышь | Движение и обзор |
| `Shift` / `Space` | Бег / прыжок |
| Левая кнопка мыши | Выстрел (зажмите, чтобы стрелять подряд) |
| `1` `2` `3` или колесо мыши | Ядро / взрывной снаряд / гравитационная сфера |
| `F5` `F6` `F7` | Построить башню / стену с аркой / пирамиду |
| `R` | Сбросить постройку и пополнить боезапас |
| `X` | Убрать осколки и отстрелянные ядра |
| `T` | Замедление времени |

### 2. Drift Racer (обе модели)

| Клавиша | Действие |
|---------|----------|
| `W` / `S` | Газ / тормоз, затем задний ход |
| `A` `D` | Руль |
| `Space` | Ручник |
| `R` | Вернуться на последний чекпоинт |
| `C` | Переключить камеру (сзади / капот) |
| `F3` | Помощь с контрруливанием вкл/выкл |

### 3. Wave Survival (обе модели)

| Ввод | Действие |
|------|----------|
| `W` `A` `S` `D`, мышь | Движение и обзор |
| `Shift` / `C` / `Space` | Бег / присед / прыжок |
| Левая / правая кнопка мыши | Огонь / прицеливание |
| `R` | Перезарядка |
| `1` `2` `3` или колесо мыши | Пистолет / автомат / дробовик |
| `F3` | Чит: сразу на пятую волну (босс) |
| `F4` (Opus) или `Shift`+`F3` (GPT) | Чит: бессмертие вкл/выкл |

Сборка GPT это *development build*, поэтому в углу вы увидите небольшую надпись «Development Build».

### 4. Living Island (обе модели)

| Ввод | Действие |
|------|----------|
| `W` `A` `S` `D`, мышь | Ходьба и вращение камеры (зайдите в воду, чтобы плыть) |
| `Shift` / `Space` | Бег / прыжок |
| `1` `2` `3` `4` `5` | Погода: ясно / облачно / дождь / туман / гроза |
| `0` | Автоматическая смена погоды вкл/выкл |
| `T` | Пауза цикла дня и ночи |
| `Tab` | Настройки: ползунок времени суток, зерно острова |
| `P` | Фоторежим |

### 5. Physics Playground (обе модели)

Выберите уровень, расставьте детали так, чтобы шарик попал в чашу, и нажмите `Space`.

| Ввод | Действие |
|------|----------|
| `1`–`9` или клик по плитке | Выбрать деталь |
| Левая кнопка мыши | Поставить деталь / выбрать поставленную (тяните, чтобы переместить) |
| `Q` / `E` | Повернуть на 15° |
| `Delete` | Удалить выбранную деталь |
| `Ctrl`+`Z` / `Ctrl`+`Y` | Отменить / повторить |
| `Space` | Запустить или поставить симуляцию на паузу |
| `R` | Вернуться в режим сборки |
| Средняя кнопка мыши / колесо / `F` | Вращение / масштаб / вернуть кадр поля |
| `F9` | Загрузить эталонное решение, затем `Space`, чтобы посмотреть |

## Что лежит в каждой папке

```
Opus 5.5/  и  GPT 6.2 Sol/
└── 1. Destruction Sandbox/ … 5. Physics Playground/
    ├── <Игра>.zip     готовая сборка для Windows (начинайте отсюда)
    ├── Source/        исходники проекта (открываются в движке)
    └── README.md      технические заметки самого ИИ-агента
```

`README.md` внутри папки игры написал ИИ-агент во время разработки. Пути из него (`Builds/`, `tools/` …) относятся к исходной рабочей папке и в этом репозитории не существуют.

### Открыть исходники (по желанию)

- **Игры на Unity** (1, 3, 4): установите Unity **6000.6.0f1**, в Unity Hub выберите *Add project from disk* и укажите папку `Source`. Первый импорт займёт несколько минут.
- **Игры на Godot** (2, 5): установите Godot **4.7.2** и импортируйте `Source/project.godot`.
- В Living Island также лежат исходные файлы Blender и Python-скрипты, которыми нейросети строили маяк, лодку, пальмы и камни.
